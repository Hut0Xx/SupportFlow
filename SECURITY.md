# Política de seguridad

## Versiones mantenidas

SupportFlow es un proyecto de portfolio. La rama `main` representa la única versión mantenida.

## Comunicar una vulnerabilidad

No abras una incidencia pública con datos sensibles, credenciales o una prueba de explotación. Contacta de forma privada con el mantenedor mediante su perfil de GitHub e incluye:

- componente y versión afectados;
- impacto observado;
- pasos mínimos para reproducirlo;
- mitigación sugerida, si existe.

No incluyas datos reales de usuarios. El mantenedor confirmará la recepción y publicará una corrección o una explicación del riesgo cuando proceda.

## Alcance

Se consideran especialmente relevantes los fallos de aislamiento entre organizaciones, autorización de adjuntos, exposición de notas internas, evasión de políticas de rol y filtración de secretos.
